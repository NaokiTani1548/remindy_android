# Remindy

リマインダーと単語学習を組み合わせた Android アプリです。
バックエンドは Spring Boot (Render にデプロイ)、フロントエンドは Jetpack Compose で実装されています。

---

## 現在の機能一覧

### 認証
| 機能 | 説明 |
|------|------|
| 新規登録 | メールアドレス・パスワードでアカウントを作成 |
| ログイン | メールアドレス・パスワードで認証し、トークンを端末に保存 |
| ログイン状態の永続化 | アプリ再起動後もトークンが有効であればログイン状態を維持 |
| ログアウト | 保存済みトークンを削除 |

---

### リマインダー
| 機能 | 説明 |
|------|------|
| 作成 / 編集 / 削除 | タイトルとスケジュールを設定してリマインダーを管理 |
| 一回限り通知 | 指定した日付・時刻に1回だけ通知 |
| 毎日繰り返し | 毎日指定時刻に通知 |
| 毎週繰り返し | 指定した曜日・時刻に毎週通知 |
| 毎月繰り返し | 指定した日にち・時刻に毎月通知 |
| 有効 / 無効の切り替え | 個別リマインダーを一時停止・再開 |
| プッシュ通知 | AlarmManager による正確な通知スケジューリング |
| 繰り返し通知の自動再登録 | 通知後、次回分を自動でスケジュール |
| 端末再起動対応 | 再起動後に全アラームを自動で復元 |

---

### 単語学習
| 機能 | 説明 |
|------|------|
| 作成 / 編集 / 削除 | 単語カードを管理 |
| QA 形式 | 質問（表）と回答（裏）のカード |
| 用語形式 | 用語（表）と詳細（裏）のカード |
| 有効 / 無効の切り替え | 通知に含めるカードを個別に管理 |
| ランダム通知 | 指定した頻度で有効なカードの中からランダムに1枚を通知 |

---

### 学習通知設定
| 機能 | 説明 |
|------|------|
| 通知のオン / オフ | 学習通知全体の有効・無効を切り替え |
| 通知頻度の選択 | 1日 1回 / 3回 / 5回 から選択 |
| アクティブ時間帯 | 9:00〜21:00（JST）の間に均等配分 |

---

### データ同期 / 永続化
| 機能 | 説明 |
|------|------|
| オフラインキャッシュ | Room データベースにデータをローカル保存 |
| 起動時同期 | アプリ起動時にバックエンドと一括同期 |
| リアルタイム UI 更新 | Room の Flow を利用したリアクティブ更新 |

---

## 技術スタック

| レイヤー | 採用技術 |
|---------|---------|
| UI | Jetpack Compose + Material3 |
| ナビゲーション | Navigation Compose |
| 状態管理 | ViewModel + StateFlow |
| ローカル DB | Room |
| 設定永続化 | DataStore Preferences |
| 通知 | AlarmManager (exact alarm) |
| 通信 | Retrofit2 + OkHttp + kotlinx.serialization |
| DI | 手動 DI (AppContainer) |
| テスト | Compose UI Test (E2E) |
| バックエンド | Spring Boot 4 (Render にデプロイ) |

---

## セットアップ

### 前提条件
- Android Studio Meerkat 以降
- Android デバイスまたはエミュレータ (API 26 以上)
- Render バックエンドが起動済みであること

### バックエンド URL の変更
`app/build.gradle.kts` の `BASE_URL` を実際のバックエンド URL に変更してください。

```kotlin
buildConfigField("String", "BASE_URL", "\"https://your-backend.onrender.com/\"")
```

### E2E テストの実行
```bash
./gradlew connectedAndroidTest
```

> **注意**: Render の無料プランはコールドスタートに最大 3 分かかる場合があります。初回テスト実行時は `warmUpBackend` が自動でバックエンドの起動を待ちます。
